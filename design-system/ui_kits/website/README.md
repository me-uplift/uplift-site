# Uplift Digital Studio — Website UI Kit

## Overview
High-fidelity component library for the Uplift Digital Studio marketing website.
Dark-mode first, gradient as hero element, all-Satoshi type system (weight-driven hierarchy).

## Design Width
1280px desktop, responsive to mobile (375px)

## Components
- `Nav.jsx` — Fixed top navigation with logo, links, CTA
- `Hero.jsx` — Full-bleed hero with gradient headline
- `Services.jsx` — Service cards grid
- `Pricing.jsx` — Three-tier pricing table
- `Testimonial.jsx` — Client testimonial / result cards
- `Footer.jsx` — Footer with logo, links, social

## Usage
All components are exported to `window` and used in `index.html`.
Design width: 1280px. View in browser at full width for best fidelity.
